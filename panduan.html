Panduan Generator Link Undangan

Petunjuk pembuatan link personal untuk para tamu undangan digital

Langkah-Langkah Membuat Link Tamu

  1. Buka Halaman Dashboard Admin:
    Akses halaman admin.html pada browser Anda.
  2. Input Nama Tamu:
    Ketik atau paste daftar nama tamu pada kotak teks. Untuk membuat banyak link sekaligus, **tulis 1 nama per baris** (gunakan tombol Enter untuk berpindah baris).
  3. Klik Tombol Generate:
    Tekan tombol "Buat Semua Link Undangan". Sistem akan otomatis memproses seluruh nama dan menyimpannya ke dalam daftar.
  4. Kirim ke Tamu Undangan:
    Gunakan tombol "Salin Link" untuk mengambil URL khusus atau tekan tombol "Kirim WA" untuk langsung membuka aplikasi WhatsApp dengan pesan ucapan yang sudah terformat rapi.

Fitur Utama Dashboard Admin

Input Sekaligus (Bulk)

Bisa memasukkan puluhan nama tamu sekaligus hanya dalam sekali klik.

Integrasi WhatsApp

Teks salam dan link otomatis tersusun rapi siap kirim ke nomor tujuan.

Penyimpanan Otomatis

Daftar nama tidak akan hilang meskipun halaman di-refresh atau ditutup.

Tips & Catatan Penting:

  • Pastikan penulisan nama menggunakan huruf kapital yang benar (contoh: Bapak Ahmad & Keluarga).
  • Nama yang diinput akan muncul di bagian sampul depan undangan digital tamu.
  • Setiap perangkat/browser menyimpan data rekapnya masing-masing secara lokal.
